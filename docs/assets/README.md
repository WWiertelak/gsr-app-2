# README images

`hero.svg` is an original vector illustration using the app's navy and teal palette.
It has an opaque background and self-contained shapes and text, so it stays legible
in GitHub's light and dark themes. Its signal traces are illustrative.

The six PNGs are unaltered browser screenshots of the running Django app in English,
at a consistent 1440 × 1000 viewport. PNG compression is lossless. The Interviews
capture is scrolled to the candidate timeline and signal chart; the other screens
are captured from the top. The Export capture includes the PDF report controls.

All recordings are synthetic, generated by `gsr.tests.sample_data.write_group`
with seed 11, a 600-second duration, and the default six shared events. The five
simulated participants are Teacher (tonic 5.0 µS), Student A (4.0 µS), Student B
(4.2 µS, coupling 0.7), Student C (4.1 µS), and Student D (3.9 µS, two own events).
Other simulation and pipeline settings use the app defaults. The interview pairs
are A + B and C + D, with Teacher assigned as the teacher.

The demo uses a separate temporary SQLite database and upload directory. No real
participant recordings, database files, or generated reports are included here.
